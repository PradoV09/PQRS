# File Upload and Management Module - Documentation

## Overview
This module implements secure file upload, storage, viewing, and downloading of attachments for PQRS in both the NestJS backend and Angular frontend.

### 4. API Endpoints

#### Files Endpoints

**GET /api/files/:storedName** - Serve file (authenticated)
- Query params: `download=true` to force download
- Headers: `Authorization: Bearer <token>`
- Returns: File with proper Content-Type and Content-Disposition headers

**GET /api/files/thumb/:thumbName** - Serve thumbnail (no auth)
- Returns: Thumbnail image (webp format)

**DELETE /api/files/:attachmentId** - Delete attachment (authenticated)
- Headers: `Authorization: Bearer <token>`
- Returns: 204 No Content
- Permission: Owner of PQRS or admin

#### PQRS Endpoints (Updated)

**POST /api/pqrs** - Create PQRS with files
- Content-Type: `multipart/form-data`
- Body fields: `titulo`, `descripcion`, `tipo`
- Files: `files` (multiple, max 5)
- Headers: `Authorization: Bearer <token>`

**POST /api/pqrs/:id/attachments** - Add files to existing PQRS
- Content-Type: `multipart/form-data`
- Files: `files` (multiple, max 5)
- Headers: `Authorization: Bearer <token>`
- Permission: Owner of PQRS or admin, PQRS state not closed

### 5. cURL Examples

#### Create PQRS with Files

```bash
curl -X POST http://localhost:3000/api/pqrs \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -F "titulo=Test PQRS with files" \
  -F "descripcion=This is a test PQRS with file attachments" \
  -F "tipo=peticion" \
  -F "files=@/path/to/image.jpg" \
  -F "files=@/path/to/document.pdf"
```

#### Add Files to Existing PQRS

```bash
curl -X POST http://localhost:3000/api/pqrs/PQRS_ID/attachments \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -F "files=@/path/to/new-file.pdf"
```

#### Download File

```bash
curl -X GET "http://localhost:3000/api/files/STORED_NAME?download=true" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -O -J
```

#### Get Thumbnail

```bash
curl -X GET http://localhost:3000/api/files/thumb/THUMB_NAME.webp \
  -o thumbnail.webp
```

#### Delete Attachment

```bash
curl -X DELETE http://localhost:3000/api/files/ATTACHMENT_ID \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

### 6. Security Features

- **Double validation**: MIME type + extension validation
- **Secure filenames**: UUID generated by server, original filename stored separately
- **Path protection**: File paths never exposed in API responses
- **Permission checks**: Download/delete endpoints verify ownership or admin role
- **Secure headers**: Content-Type, X-Content-Type-Options, Content-Disposition
- **File cleanup**: Files deleted when PQRS or attachment is deleted
- **Rate limiting**: Upload endpoints protected by ThrottlerModule
- **Size limits**: Max 10 MB per file, max 5 files per upload

### 7. Allowed File Types

**Images**: JPG, JPEG, PNG, GIF, WEBP
**Documents**: PDF, DOC, DOCX
**Videos**: MP4, MOV, AVI

## Frontend Implementation (Angular)

### 1. Components Created

- **UploadZoneComponent**: Drag & drop file upload with preview, validation, and error display
- **AttachmentGalleryComponent**: Display attachments grouped by type (images, documents, videos) with delete capability
- **FileSizePipe**: Format bytes to human-readable format (KB, MB, GB)
- **FileTypeIconPipe**: Map MIME types to icon types

### 2. Services Created

- **FilesService**: Methods for file URLs, download, delete, and additional uploads

### 3. Updated Components

- **CreatePqrsComponent**: Uses UploadZone for file selection
- **PqrsDetailComponent**: Uses AttachmentGallery for displaying and managing attachments

### 4. Error Handling

- **AuthInterceptor**: Handles upload errors with toast notifications
- **Multer errors**: File size limit, file count limit, invalid type errors

## Troubleshooting

### Common Issues

1. **Migration not running**
   - Ensure TypeORM is configured correctly in `data-source.ts`
   - Check database connection in `.env`

2. **Files not uploading**
   - Verify upload directories exist and have write permissions
   - Check Multer configuration in `multer.config.ts`
   - Verify file size and type limits

3. **Thumbnails not generating**
   - Ensure Sharp is installed correctly
   - Check if file is an image (IMAGE_MIME_TYPES)
   - Verify THUMB_DEST directory exists

4. **Permission errors**
   - Verify JWT token is valid
   - Check user role in database
   - Ensure ownership check logic is correct
